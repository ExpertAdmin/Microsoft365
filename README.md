# Microsoft 365
The Microsoft 365 Admin Center is a website where an administrator manages everything in Microsoft 365. You open it at https://admin.microsoft.com.

Think of it as a control room for your organization. From one place, you can manage people, domains, licenses, and services.

**What can you do here?**
- Add and manage users.
- Create new accounts, reset passwords, and remove users.
- Add your own domain. Use your company name in email addresses, like name@yourcompany.com.
- Assign licenses. Give each user the right apps and services, like Outlook, Teams, and Word.
- Set up email. Connect your domain to Exchange Online so your team can send and receive email.
- Manage groups and devices. Control who can access what.
- Check service health. See if any Microsoft service has a problem.
- Control billing. View your subscriptions and payments.
- Protect your organization. Set security rules and policies.
